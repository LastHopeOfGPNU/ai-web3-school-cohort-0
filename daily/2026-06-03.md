### Cobo 钱包即服务 (WaaS) 2.0 — Developer Hub

📄 文档地址：[Cobo Developer Hub](https://www.cobo.com/developers/v2/guides/overview/introduction)

#### WaaS 2.0 概览

Cobo WaaS 2.0 是一套面向开发者的钱包基础设施 API，通过统一的 REST API 提供多种钱包类型的管理能力：

**核心模块：**

1. **Overview（概述）**
   - Introduction：WaaS 2.0 定位、架构理念
   - Cobo WaaS Skill：核心能力矩阵
   - Environments：沙盒 / 生产环境
   - Authentication：API 鉴权机制
   - Permissions：权限模型
   - Error Codes：错误码体系

2. **Get Started（快速开始）**
   - Send your first request：首个 API 调用
   - Custodial Wallets (Asset)：托管型钱包入门
   - MPC Wallets (Organization-Controlled)：MPC 机构钱包入门

3. **钱包类型**
   - **Custodial Wallets**（托管钱包）：Cobo 管理私钥，适合交易所/平台
   - **MPC Wallets**（多方计算钱包）：私钥分片，机构或用户控制分片
     - Organization-Controlled：机构控制分片
     - User-Controlled：用户持有分片
   - **Smart Contract Wallets**（智能合约钱包）：基于智能合约账户

4. **Transactions（交易）**
   - 交易来源与目标
   - 手续费预估
   - 交易状态管理
   - 智能合约调用示例

5. **Webhooks & Callbacks**
   - 事件驱动的回调机制
   - Webhook 端点设置
   - 事件类型与数据格式

6. **Developer Tools**
   - Python / TypeScript SDK
   - API Playground

#### 与 Hackathon 的关联思考

- **WaaS 降低钱包集成门槛**：不需要从零实现私钥管理、签名逻辑，API 调用即可完成钱包创建、交易签名
- **MPC 方案适合 to-C 场景**：用户持有分片 = 非托管体验 + 安全阈值
- **Smart Contract Wallet 适合 Agent 场景**：可编程权限、批量交易、Gas 代付
- **Webhooks 对 AI Agent 友好**：事件驱动 → AI Agent 可以监听链上事件并自动响应

## 💡 关键收获

1. **任务推进方法论**：从 Co-learning 学到 —— 拆任务、整 proof、转问题为行动，三个循环
2. **Hackathon 实战框架**：赛道要求 → 可验证 MVP → 冲刺节奏 → 提交材料的四步拆解
3. **Cobo WaaS 2.0 定位**：不是钱包产品而是钱包基础设施 API，对标「钱包的 AWS」
4. **三种钱包模式对比**：Custodial（全托管）vs MPC（分片共管）vs Smart Contract（可编程），不同场景不同选型
5. **AI × Web3 的技术栈拼图**：WaaS 解决了「钱包/签名」层，剩下的 AI Agent 可以专注在「决策/执行」层

## 🚧 遇到的问题

- Cobo WaaS 2.0 文档中 MPC User-Controlled 方案需要客户端 SDK 集成，对纯后端 Agent 场景有额外复杂度
- 需要进一步评估 WaaS 2.0 的 API 限频和定价模型是否适合 Hackathon 阶段
