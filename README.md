# AI × Web3 School — Personal Learning Journal

> Personal learning journal and proof-of-work for AI × Web3 School.

## 关于

[AI × Web3 School](https://aiweb3.school) 是由 LXDAO 与 ETHPanda 共同发起的开源学习计划，面向 builders 系统学习 AI、区块链、智能合约、AI Agent 与去中心化 AI，并通过 Bootcamp 和项目实践连接真实协作。
